# Night 1 — первоначальный хоррор, изолированный прототип

Отдельная ветка `codex/night1-original-horror` создана от `main`. Экспедиция «Северный сигнал» в `codex/hud-status-panel` сохранена без изменений.

## Что записано в код

- Стационарная комната охраны в процедурно построенном бункере.
- Левая и правая дверь с независимым закрытием.
- Три наблюдательные камеры и переключение видов.
- Энергия: базовый расход + расход дверей/камер, при 0% двери автоматически открываются.
- Subject 06 выбирает коридор, приближается по трём стадиям и атакует открытую дверь; закрытая дверь его отгоняет.
- Победа в 06:00, поражение при проникновении, повторный запуск через «Начать ночь».
- UI на русском; Q/E — двери, 1/2/3 — камеры, C — закрыть камеры, N — начать/перезапустить.

## Локальный запуск

1. Проверь, что сохранена копия твоего локального Roblox place.
2. Переключись на ветку `codex/night1-original-horror`.
3. Запусти `rojo serve` из корня проекта.
4. В Roblox Studio открой **отдельный тестовый Place**, подключи к нему Rojo, затем нажми Play.
5. Проверь старт, обе двери, камеры, расход энергии, атаку и выигрыш по таймеру.

## Важно: чего НЕ проверяли

Код записан в GitHub, но Roblox Studio и локальный ПК сейчас недоступны. Play-тестов, тестов мобильного UI, поведения монстра в 3D, звука, визуального качества, 06:00 и перезапуска **пока нет**. Не объединяй эту ветку с main до этих проверок.

Это минимальный вертикальный срез игрового цикла, а не готовый релиз. Правильная следующая задача — Play-тест на локальном ПК и точечная коррекция обнаруженных ошибок.
